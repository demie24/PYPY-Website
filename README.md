# PYPY — Showcase & FYP Presentation Website

> **PROTECT YOUR POWER. PROTECT YOURSELF.**  
> *AI-Driven Cyber-Physical Defence for Smart Grid Digital Twin*  
> **Universiti Malaysia Perlis (UniMAP)** — FTKE 2026

An Apple-inspired interactive product storytelling and presentation showcase website designed for the Final Year Project (FYP) viva.

## Features
- **Interactive Storytelling Flow**: Guides visitors from problem definition through to autonomous cyber-physical grid self-healing.
- **IEEE 39-Bus Digital Twin**: Real-time topology inspection with telemetry HUD (voltage, active & reactive power).
- **Interactive Cyber Attack Simulation**: Multi-step simulation of FDIA, Breaker Manipulation, and Load Infiltration attacks.
- **AI Defence Architecture**: Multi-model parallel detection (Bi-LSTM, GCN, PINN, ST-GNN).
- **Verified Empirical Benchmarks**: Verified Chapter 4 metrics including AC Restoration Sandbox (<15ms) and 0.0% data leakage audit.
- **Viva Keynote Mode**: Built-in 10-slide presentation deck with speaker notes.

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Apple Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
